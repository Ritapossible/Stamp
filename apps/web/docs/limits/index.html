Honest limits

Specific beats polite. This is what Stamp does not do, and what we found in the data that it can't fix.

Scope

  1. Only orders that ask Stamp first. Binance Wallet and the Trading API don't know about Stamp tickets. A caller that skips Stamp can still trade.
  2. Buy only, spot only, BSC mainnet only, $20 an order ($50 a day for standing orders), and a person signs every fill.
  3. The server never holds a signing key. The approval is for the exact order amount, never unlimited.

The recorded close is the print at Binance's 20:00 session pause, sampled every ten minutes - close to the official close, not the auction tape. On 25 Sep NVDA's 20:00 print was 41 bps from its 19:50 print, which is why Stamp takes the paused print that follows the session, not the last one inside it.

Region

From US IP addresses the Binance Trading API answers 40304 inside an HTTP 200 - for tokenized stocks and for WBNB alike. From Frankfurt (where this server runs) the quote, approval and swap work. Decisions use public endpoints and work everywhere. Don't run execution from a US laptop or from GitHub Actions.

Execution mode

Binance's docs describe RFQ (sign typed data) for tokenized stocks. Live, from Frankfurt, it returned SWAP (a normal transaction, vendor LiquidMesh). Stamp checks SWAP by simulation and balance changes; the RFQ path is built and tested but has not been seen live.

The agent

  • x402 payment settles before the work runs; a malformed order still costs $0.02.
  • The paid route stays dormant until Binance approves a B402 merchant for the agent's wallet.
  • Paid replay protection is Studio's in-memory store, lost on restart.
  • The managed Agent Studio host is a 48-hour BSC testnet trial. Ticket data is always mainnet.

The Agentic Wallet path

  • The Agentic Wallet builds and signs the swap itself. Stamp cannot see the transaction before it is sent; it checks the quote before and the receipt after.
  • baw market-order swap is not bound to the quote. The 0.50% slippage limit is enforced by the wallet at swap time and verified by Stamp afterwards.
  • Even a quote needs a signed-in wallet, so the live path runs on your machine, not on this server.

Hosting

This site runs on a free Render instance: it sleeps when idle and has no disk, so tickets made here don't survive a restart. Every ticket still verifies offline with npm run replay or POST /v1/verify and its inputs.
