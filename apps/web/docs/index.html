Overview & quickstart

Stamp is a pre-trade gate for tokenized US stocks on BNB Smart Chain. Before an order is signed it answers one question - is this the thing you meant to buy, at a fair price, right now? - with a verdict made by code and a hash anyone can recompute.

Why it exists

A tokenized stock is not a share. On BSC one ticker can be up to three different legal products (Ondo NVDAon, xStock NVDAx, bStock NVDAB). One token can hold ten shares (NFLXon) or one (NFLXB). Tokens trade 24/7 while the stock doesn't, so a weekend price can sit well above Friday's close. And xStock's own two endpoints disagreed about how many shares NFLXx holds: 1 in one, 10 in the other.

Binance documents these rules as prose for an agent to follow. Stamp turns them into code that the agent - or the person - cannot talk its way past.

The four checks

checkrule
IssuerBuy only the policy's issuer. A cheaper sibling is listed as "not the same instrument", never bought.
SharesRead the multiplier behind every token. A bare "Buy 1 NFLX" is blocked until you say dollars or shares.
HaltCorporate actions, market pauses and a closed venue block. Missing data is never treated as "trading".
PricePrice per share vs the real stock: over 0.30% while the market is open, or 0.80% above the last close while it's shut, is a WARN, with the overpay in dollars.

The full ordered list, with every reason code, is on checks & reason codes.

Try it in the browser

  1. Open check and press Buy 1 NFLX. You get BLOCK UNIT_AMBIGUOUS with both readings.
  2. Press Buy $20 of NVIDIA. During US hours this is usually ALLOW.
  3. On an ALLOW, review & sign opens Binance Wallet. First time: an exact-amount USDT approval, then the swap.

Run it yourself (no key)

git clone https://github.com/Ritapossible/Stamp && cd Stamp
npm ci
# engine, sources, API and agent tests
npm test
# expect: 621 tickets recomputed · all hashes match
npm run replay
# this site on http://localhost:8787
npm run build && npm start

Decisions use Binance's public RWA endpoints and need no key. Execution needs a Binance Trading API key on the server (STAMP_TRADING_API_KEY, STAMP_TRADING_API_SECRET) and does not work from US IP addresses - see honest limits.

What Stamp promises, and what it doesn't

Stamp guarantees the orders that ask it first. It does not sit inside Binance's wallet or signer: a caller that skips Stamp can still trade. What it does promise is that nothing reaches your wallet from Stamp unless the decision was ALLOW, and the quote and transaction were checked against that decision.
