HTTP API

JSON over HTTPS, no key, no account. The base is https://stamp-iizn.onrender.com (a free host: the first call after a quiet spell can take ~30 s).

Decide

POST/v1/tickets

Body { intent, policy? }. Reads live Binance data and returns { ticket, verify }. 503 if Binance is unreachable - Stamp never makes a ticket from guessed data.

curl -s https://stamp-iizn.onrender.com/v1/tickets \
  -H 'content-type: application/json' \
  -d '{"intent":"Buy $20 of NVIDIA"}'

Fields you'll use most: verdict, reasons, notes, narration, chosen, rejected, multiplier, economicPriceUsd, referenceUsd, premiumBps, overpayUsd, tokenUnits, economicShares, unitReadings, hash. Money is always a decimal string, never a float.

Verify

GET/v1/tickets/:hash

The stored ticket plus the exact inputs it was decided from. Re-hashed on read; 500 if it no longer matches.

POST/v1/verify

Body { input, ticket? }. Runs the engine on input and returns { hash, verdict, reasons, matches }. See verify a ticket.

GET/v1/replay

Recomputes every recorded ticket (test cases and real captures). { ok, count, drifted, rows }.

GET/v1/summary

Live universe counts: instruments, per issuer, tickers sold by more than one issuer, largest multipliers.

Execute (a person signs)

POST/v1/execution

Body { decisionHash, user }. Only a stored ALLOW is quoted (else 409). Returns the execution ticket, plus tx (SWAP) or typedData (RFQ) only when it is ALLOW, or approvalTx when APPROVAL_REQUIRED. 501 when the server has no Trading API key.

POST/v1/execution/:hash/sent

Body { txHash }: records the transaction your wallet sent (SWAP).

POST/v1/execution/:hash/submit

Body { signature }: forwards your typed-data signature (RFQ). Refused unless the execution is ALLOW and the quote is fresh.

GET/v1/execution/:hash

Status: PENDING, FILLED or FAILED.

Standing order

GET/v1/standing
POST/v1/standing

List orders and filledTodayUsd, or create { intent, user }. One active order at a time (409).

POST/v1/standing/:id/{recheck,review,cancel,sent}

review decides again before quoting, because the last check may be ten minutes old.

Health

GET/health

{ ok, tickets, wallet }. wallet is binance-trading-api, fake (demo only, labelled) or null.
