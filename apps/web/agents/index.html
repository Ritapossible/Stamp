An agent that wants to buy a tokenized stock is the one party that shouldn't grade its own order. Stamp gives it the same ticket a person gets - same code, same hash - over HTTP, over MCP, or in front of Binance's Agentic Wallet. A paid x402 route is wired and waits on Binance's B402 approval.

Over HTTP

curl -s https://stamp-iizn.onrender.com/v1/tickets \
  -H 'content-type: application/json' \
  -d '{"intent":"Buy 1 NFLX","policy":{"issuer":"ondo"}}'

Returns { ticket, verify }. Act on ticket.verdict === "ALLOW" only. Full reference in http api.

Over MCP

{
  "mcpServers": {
    "stamp": { "url": "http://localhost:8000/mcp" }
  }
}

Install the Studio CLI (npm i -g @bnbagent/studio-cli), run bag dev from agent/, then call stamp_ticket with {"intent":"Buy $20 of NVIDIA"}. Setup in agent studio face.

In front of the Agentic Wallet

baw auth signin        # confirm in the Binance App
npm run agentic -- "Buy $20 of NVIDIA" --dry-run
npm run agentic -- "Buy $20 of NVIDIA"

An agent trading through Binance's Agentic Wallet asks Stamp first. Anything but ALLOW stops before baw is called. Then the baw quote is checked against the ticket, the swap uses the ticket's contract address and 0.50% slippage, and the BSC receipt is checked afterwards. How it works.

Three tickets, all hashed

  • Decision - the right issuer, the share count, no halt, a fair off-hours price.
  • Execution - the Agentic Wallet quote buys that token, for those dollars, within 0.50%, while both are fresh.
  • Fill - on BSC, the wallet received that token and no sibling issuer's, at a price within policy.

Paying over x402

bag x402 buy https://<agent-host>/x402 --method POST \
  --json '{"prompt":"Buy $20 of NVIDIA"}' \
  --max-usd 0.05 --asset USDT

The body comes back as {"result": "<ticket JSON>"}. Its verifyUrl opens on proof, where anyone can recompute the hash.

What the agent will not do

  • Run an LLM anywhere in the verdict. The provider is set to none.
  • Re-implement a check. It calls the Stamp API; the engine decides.
  • Sign a trade. Its wallet only receives the $0.02 and signs its own identity.
  • Pretend a paid call is free: payment settles before the work, so try the order on MCP first.
